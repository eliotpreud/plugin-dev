# Roadmap

## 0.1 — narrow prototype (implemented)

- React/TypeScript detection and bounded CSS token analysis.
- Customers UI generator with preview, explicit apply and conflict refusal.
- Local tests and example fixture.

## Next — validate integration

- Bootable host examples with two different themes.
- Compile generated TSX and run browser interaction/accessibility checks.
- Document framework and compiler compatibility from actual tests.
- AST-based detection of existing components and import conventions.
- Structured feature manifests and adapter capability reports.

## Then — expand useful modules

- Settings, notification preferences and reusable data tables.
- Permission-aware UI contracts with host-enforced authorization.
- Backend contracts with explicit tenancy and validation requirements.
- Previewable routing/import patches and a rollback/update strategy.

## Later — multiple ecosystems

- Evaluate a Laravel/PHP backend adapter and other frontend frameworks based on real host integrations.
- Add language-specific implementations against shared behavior contracts.
- Consider opt-in AI-assisted code adaptation, always showing patches for review.
- Publish eligible earlier private components after ownership, license and secret checks.

These are intentions, not shipped features or promised delivery dates.
