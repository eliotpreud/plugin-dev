# Contributing

This is an early project. Bug reports, reproducible host fixtures, accessibility feedback and improvements to integration contracts are welcome.

Use Node.js 22+ and run `npm test`. No install step is required for the CLI tests. Preview integration with `npm run demo`. Do not commit secrets, client data or private project code.

For a new adapter, first describe its detection rules, supported stack, feature boundaries and integration plan in an issue. Include a minimal host fixture and tests that exercise behavior and conflict handling. Do not advertise untested language support.

Use issues for non-sensitive bugs and feature discussions. For a sensitive issue, use GitHub private vulnerability reporting if available; otherwise contact the maintainer privately before publishing details.
